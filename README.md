  WA Instalações

Site institucional desenvolvido para a **WA Instalações**, com o objetivo de apresentar os serviços da empresa, seus projetos e formas de contato em uma página única, responsiva e de fácil navegação.

O projeto foi desenvolvido com foco em uma apresentação visual alinhada à identidade da empresa, adaptando o conteúdo para diferentes tamanhos de tela.

 Sobre o projeto

O site reúne as principais informações da WA Instalações em uma estrutura **One Page**, incluindo:

* Apresentação da empresa
* Serviços oferecidos
* Portfólio de projetos
* Depoimentos
* Formas de contato
* Acesso direto ao WhatsApp
* Formulário de contato

 Serviços apresentados

* Instalações elétricas
* Instalações hidráulicas
* Iluminação em LED
* Pequenas reformas
* Pintura residencial e comercial
* Sistemas de CFTV
* Redes lógicas
* Sistemas de detecção de incêndio
* Infraestrutura com eletrocalhas
* Montagem de quadros elétricos

 Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript
* Google Fonts
* Font Awesome
* AOS (Animate On Scroll)

 Funcionalidades

* Layout responsivo
* Navegação em formato One Page
* Menu adaptado para dispositivos móveis
* Hero com imagens em tela cheia
* Portfólio interativo
* Depoimentos
* Botão de contato via WhatsApp
* Formulário de contato
* Animações durante a navegação
* Metadados básicos para SEO e compartilhamento
* Adaptação para diferentes tamanhos de tela

 Identidade visual

A identidade visual do projeto utiliza principalmente:

* **Laranja:** `#FF6A00`
* **Preto:** `#111111`
* **Cinza metálico:** `#6E6E6E`

As cores foram utilizadas para manter uma identidade visual relacionada à proposta da empresa e destacar elementos de interação no site.
